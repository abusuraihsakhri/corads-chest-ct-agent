CO-RADS Chest CT Assessment

Structured rule-based helper with a five-lobe CT severity score (0–25).

Research/educational use only. CO-RADS is a radiologist reporting scheme. This browser tool is a deterministic approximation from a limited set of structured findings and is not a diagnostic device. Do not enter patient identifiers. All calculations run locally in the browser.
CT findings
Five-lobe CT severity score

0 = none; 1 = <5%; 2 = 5–25%; 3 = 26–50%; 4 = 51–75%; 5 = >75% involvement.

Result

Select findings and calculate the assessment.
